User-Agent Switcher Orbit · TankomoD

Издатель и область действия

Издатель: TankomoD. Контакт: tankomod@gmail.com. Действует с 18 октября 2026 года. Относится к Chrome-расширению User-Agent Switcher Orbit.

Локальные настройки

В chrome.storage.local хранятся профили, правила доменов, свой UA, язык, экран, часовой пояс и параметры WebRTC, а также кеш версий, последний пояс IANA, время проверок и ошибки. Профили приватных окон используют chrome.storage.session. Публичный IP намеренно не записывается расширением.

Доступ к вкладкам и сайтам

URL и домены открытых вкладок временно читаются локально для правил сайтов, профилей окон, обновления страницы, диагностики и выбора вкладки для необязательного геозапроса. Расширение не использует API истории, не ведёт журнал просмотров и не передаёт посещённые URL или текст страниц издателю. Диагностика читает идентификационные API, а не сообщения, пароли или формы.

Проверки версий

При установке/запуске по необходимости, примерно каждые 24 часа работы Chrome и по команде пользователя запрашиваются ChromiumDash Google, Mozilla Product Details, Microsoft Edge Updates и Brave GitHub Releases API. Это запросы метаданных версий. Сервисы видят обычные сетевые данные, включая IP и заголовки, но не получают правила доменов или историю просмотров. Ручные браузерные профили не имеют автоматического источника.

Необязательный часовой пояс по IP

Изначально выключен. Включение разрешает HTTPS-запросы к ipwho.is для получения пояса IANA по публичному IP соединения. Запрос запускает вебвкладка, чтобы учитывать прокси с маршрутизацией по вкладкам. Cookies и другие учётные данные не отправляются, referrer отключён. Точная GPS-позиция, аккаунт и посещённый URL не добавляются. Сервис неизбежно видит IP запроса и обычные сетевые метаданные. Проверки выполняются при применении/запуске и примерно раз в пять минут, если функция включена и доступна подходящая вкладка. Сохраняются пояс, время и ошибка, но не IP. Результат зависит от маршрута, геобазы, лимитов сервиса и политики безопасности сайта. Отключите функцию для прекращения запросов или выберите пояс вручную.

WebRTC и подмена API

Необязательная защита WebRTC меняет политику Chrome для UDP вне прокси и сама не передаёт WebRTC-данные издателю. Профили по команде пользователя меняют идентификационные значения, видимые сайтам. Сайты могут сохранять полученные значения по собственным правилам.

Обмен данными и аналитика

У издателя нет сервера сбора данных расширения. Нет аналитики, рекламных SDK, аккаунтов и продажи данных. Информация используется только для описанных функций. Внешние сервисы обрабатывают собственные сетевые журналы по своим правилам; издатель не контролирует сроки их хранения. Сведения о сервисах: chromiumdash.appspot.com, product-details.mozilla.org, edgeupdates.microsoft.com, api.github.com, ipwhois.io.

Хранение, удаление и поддержка

Локальные данные остаются до замены, очистки хранилища инструментами Chrome или удаления расширения. Профили приватных окон удаляются при закрытии; сессионное хранилище очищается вместе с сессией браузера. При обращении в поддержку TankomoD получает ваш email и присланные сведения; отправляйте только необходимое. Переписка хранится столько, сколько нужно для обращения и применимых правовых обязательств. Для удаления переписки пишите на tankomod@gmail.com. Удаление журналов внешних сервисов запрашивается у этих сервисов.

Безопасность и Limited Use

Внешние запросы используют HTTPS. Удалённый JavaScript не загружается и не выполняется: реализация входит в пакет, а ранние скрипты составляются из локальных функций и настроек. Использование и передача данных User-Agent Switcher Orbit соответствуют Chrome Web Store User Data Policy, включая Limited Use. Данные не используются для кредитоспособности, решений о займах, посторонней рекламы или продажи.
