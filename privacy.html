Privacy Policy

User-Agent Switcher Orbit · TankomoD

Publisher and scope

Publisher: TankomoD. Contact: tankomod@gmail.com. Effective date: October 18, 2026. This policy covers the User-Agent Switcher Orbit Chrome extension.

Local settings and temporary state

The extension stores your selected profiles, domain rules, custom User-Agent, language, screen, time-zone and WebRTC preferences in chrome.storage.local. It also caches browser release metadata, the last resolved IANA time zone, timestamps and operational errors. Private-window profile assignments use chrome.storage.session. No public IP address is intentionally stored by the extension.

Access to websites and tabs

Open-tab URLs and hostnames are read transiently to match your domain rules, assign window profiles, reload the active page, run diagnostics and choose the tab used for optional time-zone lookup. This is local handling of browsing-related information. The extension does not use the history API, create a browsing-history log, or send visited URLs or page contents to the publisher. Diagnostics read identification API values, not messages, passwords, forms or document text.

Browser version checks

At installation/startup when due, approximately every 24 hours while Chrome runs, and when you request an update, the extension contacts ChromiumDash (Google), Mozilla Product Details, Microsoft Edge Updates and the Brave GitHub Releases API. These HTTPS requests request version metadata. The services receive normal connection metadata such as the request IP and browser headers. They are not sent your domain rules or browsing history. Manual browser profiles have no automatic version source.

Optional IP-based time zone

This feature is OFF by default. Enabling it authorizes HTTPS requests to ipwho.is to resolve the public IP of that connection to an IANA time zone. A normal web tab initiates the request so tab-based proxy routing can apply. Requests omit credentials and use a no-referrer policy. No account, precise GPS position or visited URL is included. The service necessarily receives the request IP, and ordinary network metadata. Checks run on apply/startup and roughly every five minutes while enabled and a suitable tab is available. The extension stores the returned time-zone ID, check time and errors, not the IP. Routing, geolocation accuracy, rate limits and the site’s security policy may affect the result. Disable the option to stop these lookups, or use a manual time zone.

WebRTC and local API overrides

The optional WebRTC feature changes Chrome’s non-proxied UDP policy. It does not itself send WebRTC data to the publisher. Profile overrides change the identification values websites can read; this is the user-requested operation. Websites may store the values they receive under their own policies.

Sharing, analytics and sale

The publisher does not operate an extension data-collection server and the extension has no analytics, advertising SDK, account system or sale of user data. Data is used only for the features described here. The external services named above process their own connection logs under their policies; the publisher does not control their retention. Provider information: chromiumdash.appspot.com, product-details.mozilla.org, edgeupdates.microsoft.com, api.github.com and ipwhois.io.

Retention, deletion and support

Local settings and caches remain until replaced, cleared through Chrome’s extension storage tools, or removed by uninstalling the extension. Private-window assignments are removed on window closure and session storage is cleared with the browser session. If you email support, TankomoD receives your email and the information you choose to include; send only what is needed. Support messages are retained only as necessary to address the request and any applicable legal obligations. To request deletion of support correspondence, email tankomod@gmail.com. Third-party connection logs must be addressed to the relevant service.

Security and Limited Use

The extension uses HTTPS for its external endpoints, does not download or execute remote JavaScript, and packages its implementation locally. User-script code is assembled from packaged functions and local profile data. Use and transfer of user data by User-Agent Switcher Orbit adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements. Data is not used for creditworthiness, lending decisions, unrelated advertising or sale.

Changes and contact

Changes to data practices will be described in an updated policy and extension release. Contact TankomoD at tankomod@gmail.com for privacy questions.
